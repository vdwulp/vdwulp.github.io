# Package index

## Intro

Codriver brings AI code assistance directly to your cursor - no chat
window, no context switching, no copy-pasting. It reads the RStudio
editor context to determine the right action: generate new code from a
comment, complete a line, continue from context, edit existing code, or
suggest a comment.

## Get started

Use
[`codriver_configure()`](https://vdwulp.github.io/codriver/reference/codriver_configure.md)
to connect an AI provider and set up the recommended keyboard shortcut.
See [Getting
started](https://vdwulp.github.io/codriver/articles/getting-started-with-codriver.md)
for configuration guidance.

- [`codriver_configure()`](https://vdwulp.github.io/codriver/reference/codriver_configure.md)
  : Configure codriver

## Use codriver

Invoke codriver from the RStudio Addins menu or with its keyboard
shortcut (`Ctrl+/` by default). This function is not normally called
directly. See [Using
codriver](https://vdwulp.github.io/codriver/articles/start-using-codriver.md)
for an overview of modes and result presentation.

- [`codriver()`](https://vdwulp.github.io/codriver/reference/codriver.md)
  : Context-aware AI assistant for RStudio
